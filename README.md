# Awl & Stitch

A small, static, research-based leathercraft tool site for the US market. The
site is built with a zero-framework Node generator: Markdown in, static HTML
out. There is no client-side framework, no external font request, and no
third-party script.

## Requirements

- Node.js 20 or newer (tested on Node 26)
- npm
- PowerShell 5.1+ on Windows only for regenerating the PNG social images and
  icons with `System.Drawing`

## Commands

```powershell
npm install
npm run build       # writes dist/
npm run preview     # serves dist/ at http://127.0.0.1:4321/
npm run check       # link, image, JSON-LD, affiliate, sitemap, RSS checks
npm run assets      # regenerates the 28 SVG illustrations
npm run assets:og   # regenerates OG PNGs and PNG icons (Windows)
```

`SITE_URL` can override the configured domain for a preview build:

```powershell
$env:SITE_URL = "https://example.pages.dev"
npm run build
```

## Deploying to Cloudflare Pages

The output directory is `dist/`. After a successful build and check:

```powershell
npx wrangler pages deploy dist --project-name awlandstitch --branch main
```

The project is not deployed by this repository. When the custom domain is
ready, update `domain` in `src/data/site.json`, rebuild, and attach the domain
in Cloudflare Pages. Canonicals, sitemap, RSS, and OG URLs all read from that
field (or `SITE_URL`).

`public/_headers` contains security headers and long-lived cache rules for
styles, images, and OG images. It is copied to `dist/_headers` by the build.

## Site data

- `src/data/site.json` — brand, domain, title, description, author, email,
  navigation, trust-page order, article metadata, and hero-image alt text.
- `src/data/affiliates.json` — the single source of truth for affiliate
  products, prices, shipping notes, and item lists. The tracking ID is empty by
  design. The build appends it only when it is non-empty and not a placeholder.
- `content/*.md` — article and trust-page copy. The build supports the existing
  frontmatter (`title`, `metaTitle`, `metaDescription`, `slug`, `primaryKeyword`,
  `datePublished`, `dateModified`, `author`, `authorBio`, `schema`) plus visible
  `## FAQ` and `### Sources` sections in the body.

## Affiliate link rules

- Direct item URLs only. No cloaking, redirects, or link shorteners.
- Every AliExpress link is rendered with `target="_blank"` and
  `rel="sponsored nofollow noopener"`.
- If a product URL is missing or contains `PLACEHOLDER`, the build renders a
  disabled "Affiliate link pending" element with
  `data-affiliate-pending="true"` instead of a broken link.
- The affiliate disclosure appears above the first affiliate link in each
  article. The home page contains a disclosure summary but no affiliate links.
- `aff_trace_key` is added only when a real tracking ID is present in
  `src/data/affiliates.json`.

## Content and QA flags

These are intentionally reported, not silently fixed:

- The content frontmatter uses `metaTitle` / `metaDescription` and body-level
  FAQ/Sources sections rather than the generic `faq` / `sources` arrays.
- Seven `<!-- pending-link: ... -->` comments reference six planned pages that
  are not built. They are stripped from the output and are not rendered as
  links.
- `hello@awlandstitch.com` is used in the content and site config; confirm the
  mailbox exists before launch.
- Affiliate program terms (commission, cookie window, payout) are marked
  `needs verification` in `affiliates.json`.
- MOZHE and JOTUN prices are VND conversions with a ±10% caveat. The WUTA
  20-tooth listing does not name a carrier. Both are flagged in the data.
- Legal and trust pages are starter copy with `[PLACEHOLDER]` contact and
  jurisdiction details where applicable. They are not legal advice and should
  be reviewed before launch.
- The budget article has no hero image in its Markdown body. The build uses the
  generated `/images/best-budget-pricking-irons-hero.svg` from `site.json`.

## Assets

- 28 original SVG diagrams live in `public/images/`. They are generated by
  `scripts/generate-assets.mjs`; the script is deterministic.
- `public/og-default.png` and `public/og/<slug>.png` are 1200×630 PNGs
  generated by `scripts/generate-og.ps1`.
- `public/favicon.svg`, `public/favicon-32.png`,
  `public/apple-touch-icon.png`, and `public/logo-512.png` are generated
  brand assets.

## Architecture notes

- `scripts/build.mjs` reads content, renders Markdown, assembles JSON-LD,
  writes 15 HTML pages, copies `public/`, and writes sitemap, robots, and RSS.
- `src/lib/markdown.mjs` handles headings, anchors, FAQ extraction, disclosure
  boxes, table scrolling, image dimensions, and affiliate-link attributes.
- `src/lib/schema.mjs` emits one `@graph` per page. It does not emit `Review`
  markup or unverified `aggregateRating` values.
- `src/templates/` contains small HTML-string functions. There is no client
  JavaScript.
- `scripts/check.mjs` fails on missing files, broken internal links/anchors,
  missing images, unresolved affiliate tokens, invalid JSON-LD, missing
  affiliate attributes, and sitemap/robots/RSS problems. It prints warnings for
  content-contract issues and size targets.
